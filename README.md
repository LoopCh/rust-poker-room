# ♠️♥️ RustHoldem — Покерный клуб с P2P-видеочатом и авто-деплоем

Сверхлегкое приложение для игры в **Техасский Холдем (No-Limit Texas Hold'em)** с друзьями в браузере, со встроенным P2P видео- и аудиочатом за столом.

## Почему этот сервер идеально подходит для слабого VPS (512 MB RAM / 1 vCPU)?
1. **Единый бинарный файл на Rust (`axum` + `tokio`)**: статические файлы (`index.html`, `style.css`, `app.js`) вшиты внутрь исполняемого файла через `include_str!`. Не нужны Node.js, БД или внешние рантаймы.
2. **Потребление ОЗУ ~5–10 МБ**: состояние столов хранится в оперативной памяти (`DashMap` + `Mutex`).
3. **P2P WebRTC Mesh (Perfect Negotiation) для видео и звука**: видеопотоки (`320x240 @ 15fps`) и звук передаются **напрямую между браузерами игроков (Peer-to-Peer)**. Rust-сервер пересылает только текстовые сигналы установки соединения, поэтому нагрузка от видео на CPU и трафик VPS равна **0%**.
4. **Богатый UI/UX без тяжелых фреймворков**:
   * 3D-анимация раздачи и переворота карт.
   * Золотая подсветка 5 карт выигрышной комбинации на вскрытии (`Showdown`).
   * Процедурный синтезатор звуков на **Web Audio API** (раздача, стук чека, звон фишек, колокольчик хода, фанфары победы — 0 КБ внешних аудиофайлов).
   * 4 темы сукна (*Изумруд*, *Синий Роял*, *Рубин VIP*, *Оникс*) и режим **4-цветной профессиональной колоды**.
   * Живые всплывающие эмодзи-реакции над игроками (`👏`, `🔥`, `😎`, `🤔`, `😂`, `🍀`) и горячие клавиши (`F`, `C`/`Space`, `R`, `A`).

## Автоматический CI/CD деплой через GitHub Actions на слабый VPS

Поскольку компиляция Rust требует много оперативной памяти, GitHub Actions собирает статический Linux-бинарник (`x86_64-unknown-linux-musl`) на своих серверах, прогоняет все тесты (`cargo test`) и копирует уже готовый 3.5 МБ файл на ваш VPS по SSH.

### Шаг 1. Подготовьте VPS (один раз)
Скопируйте и запустите скрипт [`deploy/setup-vps.sh`](deploy/setup-vps.sh) на вашем Ubuntu/Debian VPS:
```bash
sudo bash setup-vps.sh poker.yourdomain.com
```
*(Если домена пока нет, запустите `sudo bash setup-vps.sh` без аргументов — сервер поднимется на порту `3000`).*

### Шаг 2. Добавьте секреты в GitHub репозиторий
В настройках вашего репозитория на GitHub перейдите в **Settings → Secrets and variables → Actions → New repository secret** и добавьте:
-
| Секрет | Значение |
| :--- | :--- |
| `VPS_HOST` | IP-адрес или домен вашего VPS |
| `VPS_USER` | Пользователь SSH (например, `root` или `ubuntu`) |
| `VPS_SSH_KEY` | Приватный SSH-ключ (`~/.ssh/id_ed25519` или `id_rsa`), публичная часть которого добавлена в `~/.ssh/authorized_keys` на VPS |
| `VPS_PORT` | Порт SSH (необязательно, по умолчанию `22`) |

После этого каждый `git push origin main` будет автоматически проверять код тестами, собирать релизный бинарник и обновлять сервер за 1 секунду!
